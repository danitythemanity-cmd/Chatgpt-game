# Starcade Arcade

A browser-first arcade platform with a modern homepage, game hub, and the fully playable **Nebula Drift** canvas game.

## Preview
Open `index.html` in any browser to launch the site immediately (no build steps required).

If you want a local web preview, run:

```bash
python -m http.server 8000
```

Then visit: `http://127.0.0.1:8000/index.html`

## Controls (Nebula Drift)
- **Desktop:** Arrow keys or WASD to move.
- **Touch:** Drag on the canvas or use the on-screen directional pad.

## Features
- Responsive UI for mobile and desktop
- Scoring, combos, and local high score persistence
- Web Audio API sound effects
- Smooth requestAnimationFrame-based animation
